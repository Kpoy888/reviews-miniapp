# Витрина отзывов и сертификатов — Telegram Mini App

Бесплатный прототип Mini App с отзывами о работе по **ИИ-автоматизации техподдержки** и **проектированию** (Renga, nanoCAD, Revit; BIM/ТИМ, чертежи и документация), а также вкладкой **«Сертификаты и достижения»**. Сервер не нужен: страница лежит на GitHub Pages, отзывы и сертификаты хранятся в Google-таблице, фото сертификатов — на Google Диске, бот открывает Mini App по кнопке меню.

Никаких платных тарифов: BotFather, GitHub Pages, Google Apps Script и Google Диск в этом сценарии бесплатны.

## Что получится

- Красивая страница в Telegram с двумя вкладками: **Отзывы** и **Сертификаты**.
- Услуги, средний рейтинг, фильтр по направлению, карточки отзывов и форма.
- Новые отзывы не публикуются сразу — в таблице есть столбец `approved`. Вы сами решаете, что показать.
- Вкладка сертификатов: сетка карточек с превью, названием, кем выдан, годом, необязательным описанием и ссылкой. Нажать на фото — открыть крупно. Если сертификатов ещё нет, показывается «Сертификаты скоро появятся».
- Добавлять и удалять сертификаты можете **только вы**, когда открываете Mini App из своего Telegram. У остальных вкладка только для просмотра.
- Если URL бэкенда ещё не указан или одобренных отзывов нет, на месте списка отзывов будет приглашение оставить первый отзыв. Форма при этом работает: без бэкенда отзыв не публикуется, вместо этого предлагается написать в Telegram. На вкладке сертификатов в этом случае тоже пустое состояние, а вам будет подсказка, что сначала нужно подключить Google Apps Script.

## Состав проекта

```
reviews-miniapp/
  index.html                    # страница Mini App
  styles.css                    # оформление
  app.js                        # логика, вкладки, Telegram WebApp SDK
  config.js                     # ваше имя, URL Apps Script, OWNER_TELEGRAM_ID
  apps-script/Code.gs           # бэкенд: таблица, Диск, проверка initData
  tests/initdata-hmac.test.js   # проверка алгоритма подписи Telegram
  README.md                     # эта инструкция
  screenshot.png                # снимок витрины отзывов
  screenshot-certs.png          # вкладка сертификатов (пустое состояние)
  screenshot-owner.png          # вид владельца с формой добавления
```

## 1. Подпишите витрину своим именем

Откройте `config.js` и измените:

- `OWNER_NAME` — как вас представлять (вместо «Ваше имя»);
- `OWNER_TAGLINE` — короткий слоган, если хотите другой;
- `TELEGRAM_USERNAME` — необязательно, например `ivan_petrov` (без `@`), тогда в подвале появится ссылка «Написать»;
- `OWNER_TELEGRAM_ID` — ваш числовой Telegram ID **строкой**, например `"123456789"`. Нужен, чтобы на сайте появились кнопки «Добавить» и «Удалить» только у вас. Как узнать ID — в разделе 6. Без этого поля кнопки скрыты, даже если вы уже настроили сервер.

Поле `APPS_SCRIPT_URL` пока оставьте пустым: сначала выложим таблицу и получим адрес.

Настоящая проверка прав при записи сертификатов делается **на сервере**, по свойствам скрипта, а не по `config.js`. Но чтобы кнопки было видно, ID в `config.js` всё равно нужно заполнить.

## 2. Google-таблица и Apps Script

1. Откройте [Google Таблицы](https://sheets.google.com) и создайте пустую таблицу, например «Отзывы Mini App».
2. Меню **Расширения → Apps Script**.
3. Удалите заготовку в редакторе и вставьте содержимое файла `apps-script/Code.gs`. Сохраните проект.
4. Откройте **⚙ Настройки проекта** (иконка шестерёнки слева) → раздел **Свойства скрипта** (Script properties) и добавьте два свойства:
   - `BOT_TOKEN` — токен бота, который вам выдал [@BotFather](https://t.me/BotFather) при создании бота (`/newbot` или `/mybots` → API Token). Никуда его не публикуйте и не вставляйте во фронтенд или репозиторий.
   - `OWNER_TELEGRAM_ID` — ваш числовой Telegram ID, тот же, что в `config.js`, без `@` и без кавычек, например `123456789`.
5. Выберите функцию `setup` в списке функций сверху и нажмите **Выполнить**. Google попросит разрешение:
   - выберите свой аккаунт;
   - если появится «Приложение не проверено», нажмите **Дополнительно → Перейти на страницу проекта (небезопасно)** — это ваш собственный скрипт;
   - разрешите доступ к **таблице** и к **Google Диску** (папка для фото сертификатов создаётся автоматически).
6. **Развернуть → Новое развёртывание**:
   - тип: **Веб-приложение**;
   - описание: например `reviews-v2`;
   - **Выполнять как:** Меня;
   - **У кого есть доступ:** Все.
7. Нажмите **Развернуть** и скопируйте URL вида  
   `https://script.google.com/macros/s/XXXX/exec`.
8. Вставьте этот URL в `config.js` в поле `APPS_SCRIPT_URL`.

Если вы уже публиковали предыдущую версию скрипта, после замены `Code.gs` обязательно:

1. Снова запустите `setup()` — появятся лист `Certificates` и папка на Диске, плюс Google запросит доступ к Диску, если его ещё не было.
2. Сделайте **Развернуть → Управление развёртываниями → карандаш → Новая версия**. Иначе сайт продолжит ходить в старый код. URL при этом обычно не меняется.

### Модерация отзывов

В таблице появится лист `Reviews`. Новые строки приходят с `approved = FALSE`. Чтобы отзыв показался в Mini App, поставьте в этом столбце галочку / `TRUE`. Остальные столбцы лучше не переименовывать.

Антиспам: один и тот же пользователь Telegram (по `telegramId`) не может отправить отзыв чаще, чем раз в 15 минут. Если Mini App передал подписанный `initData`, сервер берёт доверенный `user.id` из него. Если `initData` нет (например, отзыв из обычного браузера), используется прежнее поведение. Лимиты длины текста: от 10 до 1000 символов, оценка — только 1–5, направление — только два рабочих варианта.

Таблицу целиком публиковать не нужно. Доступен только веб-адрес скрипта, а на сайт уходят лишь одобренные отзывы.

### Как хранятся сертификаты

- Лист `Certificates` с колонками: `id`, `created_at`, `title`, `issuer`, `year`, `description`, `link`, `image_file_id`, `image_url`.
- Папку на Google Диске создаёт `setup()`. Она (и каждый файл) открыты как **«Доступны всем, у кого есть ссылка» — Просмотр**, чтобы превью работало в `<img>` на сайте.
- Для изображений в таблицу пишется публичный URL вида  
  `https://drive.google.com/thumbnail?id=FILE_ID&sz=w1600`  
  (запасной формат: `https://lh3.googleusercontent.com/d/FILE_ID=w1600`).
- PDF сохраняется на Диск, в карточке показывается заглушка, ссылка ведёт на `https://drive.google.com/file/d/FILE_ID/view`.
- Удаление сертификата (только владелец) убирает строку из таблицы и отправляет файл в корзину Диска.

Перед отправкой сайт сам сжимает фото примерно до 1600 пикселей по длинной стороне (JPEG) и передаёт его как base64 в `POST` с `Content-Type: text/plain`.

## 3. Выложите страницу на GitHub Pages

1. Зарегистрируйтесь или войдите на [GitHub](https://github.com) (бесплатный аккаунт).
2. **New repository** — создайте репозиторий, например `reviews-miniapp`. Можно без README, если загружаете уже готовые файлы.
3. Загрузите в корень репозитория файлы:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `config.js` (уже с URL Apps Script, вашим именем и `OWNER_TELEGRAM_ID`)
   - при желании `README.md`, папку `apps-script` и `tests`
4. В репозитории откройте **Settings → Pages**:
   - Source: **Deploy from a branch** (или **GitHub Actions**, если так уже настроено);
   - Branch: `main` (или `master`), папка `/ (root)`;
   - Save.
5. Через одну-две минуты адрес будет таким:  
   `https://<ваш-логин>.github.io/reviews-miniapp/`  
   (имя репозитория в конце должно совпадать).

Проверьте ссылку в браузере: должна открыться витрина. Если URL скрипта ещё не указан или одобренных отзывов нет, список будет пустым — это нормально. После подключения таблицы на витрине появятся только отзывы с `approved = TRUE`. Сертификаты, которые вы добавите из Telegram, появятся сразу.

## 4. Создайте бота и подключите Mini App

1. В Telegram откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Укажите имя (как бот будет отображаться) и username — он должен заканчиваться на `bot`, например `my_reviews_bot`.
3. Сохраните токен: вставьте его в свойство скрипта `BOT_TOKEN` (раздел 2). Не публикуйте токен в GitHub и не пишите его в `config.js`.
4. Подключите Mini App одним из способов (можно обоими).

### Способ А. Кнопка меню (удобно для повседневной работы)

1. В BotFather: `/mybots` → ваш бот → **Bot Settings → Menu Button**.
2. **Configure menu button** (или «Configure Menu Button»).
3. Отправьте URL GitHub Pages, например `https://username.github.io/reviews-miniapp/`.
4. Задайте подпись кнопки, например «Отзывы».

После этого в чате с ботом внизу появится кнопка, которая открывает Mini App.

### Способ Б. Полноценное Mini App и прямая ссылка

1. В BotFather отправьте `/newapp`.
2. Выберите бота, укажите заголовок, короткое описание, фото (квадратное, не меньше 640×640) и short name, например `reviews`.
3. В качестве Web App URL снова укажите адрес GitHub Pages.

Клиенты смогут открывать витрину по ссылке вида  
`https://t.me/<bot_username>/<short_name>`.

Дополнительно можно задать описание бота через `/setdescription` и картинку через `/setuserpic`.

## 5. Как проверить, что всё работает

1. Откройте бота в Telegram и нажмите кнопку меню / ссылку Mini App.
2. Должны подхватиться тема Telegram и ваше имя в форме (из профиля).
3. Отправьте тестовый отзыв. В таблице появится новая строка с `approved = FALSE`.
4. Поставьте `TRUE` и обновите Mini App — отзыв появится в списке.
5. Если открыть тот же адрес в обычном браузере, приложение тоже работает; в Telegram дополнительно подставляются тема и имя из профиля. Кнопки добавления сертификатов в браузере не появятся — это сделано специально.

Отправка идёт как `POST` с `Content-Type: text/plain`, чтобы обойти CORS-preflight Apps Script. Список отзывов читается через обычный `GET`, список сертификатов — через `GET ?type=certificates`. Если браузер заблокирует запрос, фронтенд автоматически попробует JSONP.

Проверить алгоритм подписи Telegram на своей машине:

```bash
node tests/initdata-hmac.test.js
```

## 6. Сертификаты: Telegram ID и как добавить карточку

### Как узнать свой Telegram ID

1. В Telegram откройте [@userinfobot](https://t.me/userinfobot) и нажмите **Start**.
2. Бот пришлёт ваш числовой Id, например `123456789`. Это не username и не номер телефона.
3. Вставьте его:
   - в `config.js` как строку: `OWNER_TELEGRAM_ID: "123456789"`;
   - в свойства скрипта Apps Script как `OWNER_TELEGRAM_ID` = `123456789`.
4. Залейте обновлённый `config.js` на GitHub Pages.

### Как добавить сертификат из Telegram

1. Убедитесь, что выполнены шаги из разделов 2–4: свойства `BOT_TOKEN` и `OWNER_TELEGRAM_ID` заданы, `setup()` запускали, веб-приложение переразвёрнуто новой версией, в `config.js` стоят и URL скрипта, и ваш ID.
2. Откройте Mini App **из своего аккаунта** через кнопку меню бота (не из чужого Telegram и не просто в браузере).
3. Перейдите на вкладку **«Сертификаты»**.
4. Нажмите **«Добавить»**, заполните название, кем выдан, год, по желанию описание и ссылку, приложите фото или PDF.
5. Нажмите **«Сохранить»**. Карточка появится на витрине сразу, без модерации.
6. Чтобы убрать карточку, нажмите **«Удалить»** на ней (кнопка видна только вам).

Если кнопки «Добавить» нет: проверьте, что в `config.js` указан именно ваш ID, файл залит на Pages, и вы открыли приложение из Telegram под этим аккаунтом. Если кнопка есть, но сохранить не удаётся — проверьте свойства скрипта, новую версию развёртывания и что Mini App открыт не старше суток (подпись `initData` принимается не дольше 24 часов; просто закройте и откройте приложение снова).

## Частые вопросы

**Отзыв отправился, но на сайте его нет.**  
Он ждёт модерации. Откройте таблицу и отметьте `approved`.

**Сайт пишет, что не удалось загрузить отзывы или сертификаты.**  
Проверьте URL в `config.js` (должен заканчиваться на `/exec`), доступ веб-приложения («Все») и что после правок кода выпущены новая версия развёртывания. Затем заново залейте `config.js` на GitHub Pages.

**Изменил config.js, а на сайте старые данные.**  
Подождите минуту-две или сделайте принудительное обновление страницы. У GitHub Pages бывает короткая задержка.

**Нужно ли платить за хостинг или Google Workspace?**  
Нет. Хватит обычного Google-аккаунта и бесплатного GitHub. Не включайте платные опции Pages и не подключайте свой домен, если хотите остаться на нулевом бюджете.

**Можно ли открыть проект без Telegram, чтобы просто посмотреть?**  
Да. Откройте `index.html` через любой статический хостинг или локально (см. ниже). Если бэкенд ещё не подключён, список отзывов и сертификатов будет пустым, а после отправки формы отзыва появится предложение написать в Telegram. Добавлять сертификаты из браузера нельзя — только из вашего Telegram.

**Безопасно ли поле OWNER_TELEGRAM_ID в config.js?**  
Оно только прячет или показывает кнопки в интерфейсе. Записать или удалить сертификат без действительной подписи Telegram и совпадения `user.id` со свойством скрипта нельзя: подделать `initDataUnsafe` в браузере недостаточно.

### Локальный просмотр

```bash
cd reviews-miniapp
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080` в браузере. Вкладка сертификатов: `http://localhost:8080/#certificates`.

## Приватность

В таблицу могут попасть имя, текст отзыва, оценка, направление, идентификатор и username Telegram, если Mini App открыт из Telegram. Файлы сертификатов доступны всем, у кого есть прямая ссылка на файл (так работает превью на сайте). Не делитесь таблицей на редактирование и **никогда не публикуйте токен бота**.
